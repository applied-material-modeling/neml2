# ScalarMagnitudeGate

**Source:** `models/common/MagnitudeGate.py`

Substitute a `Scalar` while a reference is negligible.

See `_MagnitudeGate` for the switch and its derivative.

## Inputs

`prediction` &mdash; `input` &middot; `Scalar` &middot; **required**
: The value substituted in while the reference is negligible.

`reference` &mdash; `input` &middot; `Scalar` &middot; **required**
: The value whose norm decides the switch, and the fallback above the threshold. For a warm start this is the previous converged value of the quantity being predicted.


## Outputs

`gated` &mdash; `output` &middot; `Scalar` &middot; **required**
: The prediction while the reference is negligible, the reference otherwise.


## Parameters

`threshold` &mdash; `parameter` &middot; `Scalar` &middot; default `1e-3`
: Substitute the prediction only while the reference's norm is below this.
