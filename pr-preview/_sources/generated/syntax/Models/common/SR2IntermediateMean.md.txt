# SR2IntermediateMean

**Source:** `models/common/IntermediateReduce.py`

``to = mean(from, dim=sub_batch_axis)``; reduces sub_batch_ndim by 1.

Mirrors C++ ``IntermediateMean<SR2>``. Used in CP to average per-crystal
cauchy stress into a mean over crystals (taylor-style homogenisation).

## Inputs

`from` &mdash; `input` &middot; `SR2` &middot; **required**
: Input tensor to average


## Outputs

`to` &mdash; `output` &middot; `SR2` &middot; **required**
: Averaged tensor


## Other options

`dim` &mdash; `int` &middot; default `-1`
: Sub-batch dimension to average
