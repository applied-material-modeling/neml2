# SR2IntermediateSum

**Source:** `models/common/IntermediateReduce.py`

``to = sum(from, dim=sub_batch_axis)``; reduces sub_batch_ndim by 1.

Mirrors C++ ``IntermediateSum<SR2>``.

## Inputs

`from` &mdash; `input` &middot; `SR2` &middot; **required**
: Variable to reduce


## Outputs

`to` &mdash; `output` &middot; `SR2` &middot; **required**
: The reduced variable


## Other options

`dim` &mdash; `int` &middot; default `-1`
: Sub-batch dimension to sum
