# BilinearTraction

**Source:** `models/solid_mechanics/traction_separation_law/BilinearTraction.py`

Assemble bilinear cohesive traction from an externally updated damage.

## Inputs

`damage` &mdash; `input` &middot; `Scalar` &middot; **required**
: Current damage

`normal_separation` &mdash; `input` &middot; `Scalar` &middot; **required**
: Normal opening separation

`normal_penetration` &mdash; `input` &middot; `Scalar`
: Optional normal penetration included through the penalty term

`tangential_separation_1` &mdash; `input` &middot; `Scalar` &middot; **required**
: First tangential separation

`tangential_separation_2` &mdash; `input` &middot; `Scalar` &middot; **required**
: Second tangential separation


## Outputs

`traction` &mdash; `output` &middot; `Vec` &middot; **required**
: Traction vector


## Parameters

`penalty_stiffness` &mdash; `parameter` &middot; `Scalar` &middot; **required**
: Penalty stiffness
